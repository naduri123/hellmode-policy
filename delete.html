헬모드 계정·데이터 삭제

앱: 헬모드 (Hell Mode) · 개발자: SiCon · 문의: hellmodesicon@gmail.com

헬모드의 계정과 게임 데이터는 아래 두 가지 방법 중 하나로 삭제할 수 있습니다.

방법 1. 게임 안에서 바로 삭제

  1. 헬모드를 실행합니다.
  2. 시작 화면에서 도움말을 엽니다.
  3. [계정·데이터 삭제]를 누르고, 확인 창에서 삭제를 확정합니다.

즉시 클라우드 계정, 클라우드 저장, 이 기기의 저장이 모두 삭제됩니다.

방법 2. 웹에서 요청 (게임을 지웠거나 실행할 수 없을 때)

아래 버튼으로 삭제 요청서를 보내 주세요. 플레이어 ID가 있으면 가장 빠르게 처리됩니다.

삭제 요청하기

플레이어 ID 찾는 법: 게임의 도움말 → [계정·데이터 삭제] 위에 있는 플레이어 ID (복사 버튼으로 복사할 수 있습니다)

게임을 이미 지웠다면: 구글로 로그인했던 경우 게임을 다시 설치해 같은 구글 계정으로 로그인하면 같은 플레이어 ID가 보입니다. 이때는 게임 안에서 바로 삭제해도 됩니다. 게스트로만 이용했다면 데이터가 이름 없이 저장되어 있어 플레이어 ID 없이는 찾을 수 없습니다.

요청서를 쓸 수 없다면 hellmodesicon@gmail.com 으로 제목 "헬모드 계정 삭제 요청"과 플레이어 ID(또는 구글 플레이 게임즈 닉네임)를 보내 주세요. 접수 후 영업일 기준 7일 안에 처리합니다.

삭제되는 데이터

  • 게임용 플레이어 ID와 클라우드 계정
  • 클라우드에 저장된 게임 진행 기록 (스테이지, 재화, 아이템, 설정 등)
  • 기기에 저장된 게임 데이터 (방법 1의 경우)

보관되는 데이터

  • 유료 상품 결제 기록은 「전자상거래 등에서의 소비자보호에 관한 법률」에 따라 최대 5년간 보관한 뒤 삭제합니다.
  • 구글 계정과 구글 플레이 게임즈 프로필은 구글이 관리하므로 이 절차로 삭제되지 않습니다.

삭제된 데이터는 되살릴 수 없습니다. 자세한 내용은 개인정보처리방침을 참고하세요.

Hell Mode Account & Data Deletion

App: Hell Mode · Developer: SiCon · Contact: hellmodesicon@gmail.com

You can delete your Hell Mode account and game data in either of the two ways below.

Option 1. Delete in the Game

  1. Open Hell Mode.
  2. Open Help from the start screen.
  3. Tap [Delete account & data] and confirm.

Your cloud account, cloud save and the save on this device are deleted immediately.

Option 2. Request on the Web (if you uninstalled the Game or can't open it)

Send a deletion request with the button below. Including your Player ID makes it fastest.

Request deletion

Finding your Player ID: in the Game, Help → Player ID above [Delete account & data] (tap Copy to copy it).

Already uninstalled? If you signed in with Google, reinstall the Game and sign in with the same Google account to see the same Player ID — you can also delete directly in the Game then. If you only played as a guest, your data is stored without a name and can't be found without the Player ID.

If you can't use the form, email hellmodesicon@gmail.com with the subject "Hell Mode account deletion request" and your Player ID (or Google Play Games nickname). Requests are completed within 7 business days.

Data That Is Deleted

  • Your game player ID and cloud account
  • Game progress saved in the cloud (stages, currency, items, settings, etc.)
  • Game data stored on your device (Option 1)

Data That Is Kept

  • Purchase records are kept for up to 5 years as required by Korean consumer protection law, then deleted.
  • Your Google account and Google Play Games profile are managed by Google and are not deleted by this process.

Deleted data cannot be restored. See our Privacy Policy for details.
